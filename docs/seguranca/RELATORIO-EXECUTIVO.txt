                            TOP 3 CENÁRIOS DE ATAQUE

CENÁRIO 1: Bloqueio de Sistema
┌─────────────────────────────────────────────────────────────────┐
│ 1. Atacante (anônimo) descobre UUID de recurso crítico         │
│ 2. POST /manutencoes → Cria manutenção indefinida              │
│ 3. Recurso está 100% bloqueado                                  │
│ 4. Negócio parado até admin deletar manutenção manualmente    │
│                                                                 │
│ Tempo para executar: < 10 segundos                             │
│ Conhecimento técnico necessário: Mínimo                        │
│ Impacto: CRÍTICO (sistema indisponível)                        │
└─────────────────────────────────────────────────────────────────┘

CENÁRIO 2: Escalação de Privilégio (Usuário → Admin)
┌─────────────────────────────────────────────────────────────────┐
│ 1. Atacante cria conta como Solicitante (POST /usuarios)        │
│ 2. Obtém UUID de um Admin (GET /usuarios)                       │
│ 3. PUT /usuarios/{admin-uuid} com perfil=SOLICITANTE            │
│ 4. Agora é Admin (ou conseguiu descobrir seus dados)            │
│ 5. DELETE todos os usuários legítimos                           │
│                                                                 │
│ Tempo para executar: < 1 minuto                                │
│ Conhecimento técnico: Baixo (curl + UUIDs)                     │
│ Impacto: CRÍTICO (invasão total)                               │
└─────────────────────────────────────────────────────────────────┘

CENÁRIO 3: Deleção em Cascata
┌─────────────────────────────────────────────────────────────────┐
│ 1. DELETE /usuarios/{id} × 10 → Remove usuários                 │
│ 2. DELETE /recursos/{id} × 20 → Remove recursos                 │
│ 3. DELETE /manutencoes/{id} não existe, mas POST cria bloqueios  │
│ 4. Sistema inoperável                                           │
│                                                                 │
│ Tempo para executar: < 5 minutos (script automatizado)         │
│ Conhecimento técnico: Médio (automação)                        │
│ Impacto: CRÍTICO (perda de dados)                              │
└─────────────────────────────────────────────────────────────────┘
